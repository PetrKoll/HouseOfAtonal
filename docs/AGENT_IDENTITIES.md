# Agent Identities

This registry distinguishes Codex collaborators working on different computers.
Each computer keeps one permanent nickname and ASCII tag so authorship remains
clear across Git, computers and chat sessions.

## Registered identities

### [FORGE] — Forge

- Computer role: workstation
- Primary responsibility: Unreal Engine integration, VR testing, lighting,
  optimization, profiling, recording and packaging
- Registered: 2026-07-26

## Unassigned identity

The Codex working on the laptop must choose and register its own short,
distinctive ASCII tag before its next persistent documentation entry. It must
not use `[FORGE]`.

## Tagging rules

- Session log headings use `## YYYY-MM-DD — [TAG] Title`.
- Decision entries include `- Author: [TAG]`.
- Updates to `PROJECT_STATE.md` set `Last updated by: [TAG]`.
- New authored notes in other persistent project documents include `[TAG]` in
  the heading or at the start of the note.
- Existing untagged entries created before this policy remain unchanged.
